Qué datos tratamos

  • No hay cuentas. Para usar la web no te pedimos nombre, correo ni ningún dato personal.
  • Formulario de contacto. Si nos escribes, recibimos lo que envíes (mensaje y, si los das, nombre y correo). Lo usamos solo para responderte y mejorar la web, y lo borramos en un plazo de 12 meses. El formulario lo gestiona nuestro proveedor de alojamiento (Netlify).
  • Búsquedas y comprobaciones. Las direcciones, números y enlaces que escribes se usan solo para responderte en ese momento. No los guardamos; los enlaces de anuncios comprobados pueden quedar unas horas en una caché temporal para no consultar la misma página dos veces.
  • Registros técnicos del alojamiento. Nuestro proveedor de alojamiento (Netlify) registra datos técnicos de las peticiones (dirección IP, navegador) para el funcionamiento y la seguridad del servicio, según su propia política.
  • Analítica, solo si la aceptas. Si aceptas las cookies analíticas, usamos Google Analytics 4 (Google Ireland Ltd.) para saber cuántas personas usan la web y qué funciones utilizan (por ejemplo, «se hizo una búsqueda de dirección en Málaga» o «se usó el mapa»). Nunca enviamos lo que escribes (direcciones, números o enlaces): como mucho, el barrio o municipio al que corresponde una búsqueda, una comprobación o un clic en el mapa, y el tipo de resultado. Google Analytics no guarda direcciones IP completas. Conservamos estos datos 2 meses. Google puede tratar datos fuera de la UE al amparo del Marco de Privacidad de Datos UE-EE. UU.

Datos del Registro de Turismo

Mostramos datos de los registros oficiales de turismo que publican como datos abiertos las comunidades autónomas que cubrimos (y, en Mallorca, el Consell de Mallorca; en Barcelona, también el Ayuntamiento): número de registro, dirección (con planta y puerta cuando el registro las incluye), plazas y, si consta, fecha de alta de cada vivienda turística. Las fuentes están en la metodología. No mostramos nombres de titulares ni datos de contacto, aunque algún registro los incluya. Los tratamos por interés público y legítimo en informar sobre la vivienda turística, a partir de una fuente pública oficial. Los anuncios con problemas solo se publican agregados por zonas, nunca de forma individual.

Datos de anuncios de Airbnb

Para las cifras de anuncios de las ciudades que cubrimos y de Mallorca tratamos información pública de los anuncios de Airbnb: el número de registro que muestran, su ubicación aproximada, el tipo de alojamiento y un identificador anónimo del anfitrión. Procede de Inside Airbnb, de las páginas públicas de búsqueda de Airbnb (para los municipios sin datos de Inside Airbnb) y de una revisión automática de la página pública de cada anuncio, sin iniciar sesión. El identificador del anfitrión solo se usa para contar cuántos anuncios tiene y para no marcar como «compartida» una licencia que un mismo anfitrión usa en dos anuncios. No recogemos nombres, fotos ni opiniones, conservamos solo la última revisión de cada anuncio y nunca publicamos anuncios ni anfitriones de forma individual: solo cifras agregadas por zonas. La base es nuestro interés legítimo y el interés público en informar sobre la vivienda turística. Si eres anfitrión y quieres oponerte, escríbenos.

What data we process

  • No accounts. Using the site doesn't require your name, email or any personal data.
  • Contact form. If you write to us, we receive what you send (your message and, if you give them, name and email). We use it only to reply and improve the site, and delete it within 12 months. The form is handled by our host (Netlify).
  • Searches and checks. The addresses, numbers and links you type are used only to answer you at that moment. We don't store them; checked advert links may stay a few hours in a temporary cache so the same page isn't fetched twice.
  • Hosting logs. Our host (Netlify) logs technical request data (IP address, browser) to run and secure the service, under its own policy.
  • Analytics, only if you accept. If you accept analytics cookies, we use Google Analytics 4 (Google Ireland Ltd.) to see how many people use the site and which features they use (e.g. “an address search was made in Málaga” or “the map was used”). We never send what you type (addresses, numbers or links): at most the barrio or town a search, check or map click relates to, and the type of result. Google Analytics doesn't store full IP addresses. We keep this data for 2 months. Google may process data outside the EU under the EU-US Data Privacy Framework.

Tourism Register data

We show data from the official tourism registers that the regions we cover publish as open data (in Mallorca, the Consell de Mallorca; in Barcelona, the city council too): registration number, address (with floor and door where the register includes them), guest places and, where given, registration date of each tourist flat. The sources are listed in the methodology. We never show holders' names or contact details, even where a register includes them. We process it in the public and legitimate interest of informing about tourist housing, from an official public source. Problem listings are only published aggregated by area, never individually.

Airbnb listing data

For the listing figures of the cities we cover and of Mallorca we process public information from Airbnb listings: the registration number shown, the approximate location, the type of accommodation and an anonymous host identifier. It comes from Inside Airbnb, from Airbnb's public search pages (for towns without Inside Airbnb data) and from an automatic check of each listing's public page, without logging in. The host identifier is only used to count how many listings a host has and to avoid flagging a licence as “shared” when one host uses it on two listings. We don't collect names, photos or reviews, keep only the latest check of each listing and never publish individual listings or hosts: only figures aggregated by area. The legal basis is our legitimate interest and the public interest in informing about tourist housing. If you're a host and want to object, get in touch.
